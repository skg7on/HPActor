HPActor Developer Manual

HPActor is a C++20 event-based actor framework for building scalable, high-performance distributed applications. Inspired by CAF (C++ Actor Framework), it provides cooperative scheduling, hierarchical supervision, pluggable service discovery, and a production reliability plane with delivery semantics, bounded mailboxes, dead-letter queues, distributed tracing, and deterministic fault injection.

This manual is the authoritative guide for developing, deploying, monitoring, and operating HPActor-based systems.
