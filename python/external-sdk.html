External Client SDK

The hpactor.client package provides sync and async clients for HPActor health, metrics, HTTP gateway, and CLI surfaces. It is pure Python — it never imports the _hpactor native extension.

from hpactor.client import (
    AsyncHPActorClient,
    HealthClientConfig,
    HPActorClientConfig,
    HttpEndpointConfig,
    MetricsClientConfig,
)

endpoint = HttpEndpointConfig(base_url="https://node.example")
config = HPActorClientConfig(
    health=HealthClientConfig(endpoint=endpoint),
    metrics=MetricsClientConfig(endpoint=endpoint),
)

async with AsyncHPActorClient(config) as client:
    readiness = await client.health.readiness()
    metrics = await client.metrics.scrape()

Configuration

All configuration types are frozen, validated, and secret-redacted.

class HttpEndpointConfig
base_url: str
verify: bool | ssl.SSLContext
follow_redirects: bool
timeouts: HttpTimeouts
limits: HttpLimits
retry: RetryPolicy
class HttpTimeouts
connect: float = 5.0
read: float = 30.0
write: float = 30.0
pool: float = 5.0
class HttpLimits
max_keepalive_connections: int = 20
max_connections: int = 100
max_response_bytes: int = 16 MiB
class RetryPolicy

Opt-in. Applies only to explicitly idempotent requests.

attempts: int = 1  (max 3)
initial_delay: float = 0.1
max_delay: float = 2.0
retry_statuses: frozenset[int] = {429, 502, 503, 504}

CLI Client

class CliClient
class AsyncCliClient

Communicates over Unix-domain sockets or TCP using the HPAC framing protocol (ASCII HPAC, big-endian 32-bit payload length, protobuf body — byte-compatible with the C++ CliProtoServerActor).

execute(path, *, params=None, args=(), fmt='pretty') → CliResult

Execute a command-tree path. Raises CliCommandError if the server returns is_error=True.

inspect(actor_id) → InspectStateReply
kill(actor_id, *, force=False) → KillReply
quarantine(actor_id, reason='') → QuarantineReply
unquarantine(actor_id) → QuarantineReply
list_actors(shard_index=0, offset=0, limit=100, filter_str='') → ListActorsReply
system_stats() → SystemStatsReply
memory_stats(actor_id=0) → MemoryStatsReply
call(rpc_method, request, response_type) → Message

Forward-compatible low-level RPC for implemented methods.

class CliClientConfig
uds_path: str | None = "/tmp/hpactor/hpactor.sock"
host: str | None
port: int | None
connect_timeout: float = 5.0
request_timeout: float = 10.0
max_inbound_payload: int = 16 MiB
max_outbound_payload: int = 16 MiB
allow_insecure_remote_tcp: bool = False

Non-loopback TCP requires allow_insecure_remote_tcp=True. Loopback addresses (127.0.0.0/8, ::1, localhost) are permitted without the opt-in.

Bundle

class HPActorClient
class AsyncHPActorClient

Thin configured bundle that constructs only the requested capabilities:

config = HPActorClientConfig(
    health=HealthClientConfig(endpoint=endpoint),
    cli=CliClientConfig(uds_path="/tmp/hpactor/hpactor.sock"),
)
with HPActorClient(config) as client:
    print(client.capabilities)   # {HEALTH, CLI}
    client.health.liveness()     # OK
    client.metrics.scrape()      # raises UnsupportedCapability
capabilities: frozenset[Capability]

Accessing a capability not in capabilities raises UnsupportedCapability with the capability name.

Bounds and Security

  • Response bodies are bounded at 16 MiB by default. Streaming reads accumulate until the limit; exceeding it raises ResponseLimitError.

  • Redirect following is off by default.

  • TLS verification is on by default.

  • Retries are off by default and require an explicit RetryPolicy and idempotency declaration.

  • CLI commands are never retried — the server may have executed the command before the response connection failed.

  • Non-loopback CLI TCP requires allow_insecure_remote_tcp=True and emits a warning. The manual recommends UDS or an authenticated proxy for production.

  • Diagnostic payloads in exceptions are truncated to 4 KiB.

Server-Side Requirements

Each client expects explicit server-side configuration:

  • Health — an HTTP listener with HealthHttpServer attached

  • Metrics — an explicitly exposed route returning MetricsActor output (not an automatic /metrics listener)

  • Gateway — HTTPGatewayActor with registered application routes

  • CLI — CliProtoServerActor listening on UDS or trusted TCP
