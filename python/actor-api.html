Actor API Reference

This page covers the imperative Python actor programming model — defining actors, sending messages, asking for replies, and using delivery options.

ActorSystem

class ActorSystem

The main entry point for the in-process actor runtime.

classmethod from_topology(path, *, messages, policy, config=None)

Construct a system for declarative TOML topology bootstrap. Side-effect free — no threads or native state until __aenter__.

async spawn(actor_class, *, args=None, messages, delivery=None)

Spawn a new actor. Returns an ActorAddress.

Parameters:

  • actor_class (type) – An Actor subclass decorated with @actor().

  • args (dict) – Keyword arguments forwarded to the constructor.

  • messages (MessageRegistry) – Frozen protobuf message registry.

  • delivery (DeliveryOptions) – Optional delivery mode and deadline.

async send(target, message, *, options=None)

Send a fire-and-forget message to target.

async ask(target, message, *, timeout=5.0, options=None)

Send a request and await a typed response. Raises AskTimeoutError if no response arrives within timeout seconds.

resolve(name)

Look up a named actor. Returns an ActorAddress or raises KeyError.

async schedule(target, delay, message)

Deliver message to target after delay seconds.

async __aenter__()

Start the native runtime. All actor state is initialized.

async __aexit__(*args)

Initiate graceful drain, stop all actors, join threads.

Actor

class Actor

Base class for all Python actors.

behavior() → Behavior

Return a Behavior with registered message handlers. Called once at startup. The behavior is frozen after construction.

async on_start()

Called after the actor is published and the system is running.

async on_stop()

Called during graceful shutdown before the actor is removed.

async on_restart()

Called before a new incarnation, if supervision restarts the actor.

Behavior

class Behavior

Immutable message handler table.

on(message_type, handler)

Register handler for a protobuf message class.

Handler signature: async def handler(msg, ctx) where msg is the deserialized protobuf message and ctx is an ActorContext.

on_request(request_type, response_type, handler)

Register a request-response handler. Handler must return a protobuf response message or raise an error.

ActorContext

class ActorContext

Handler-scoped context providing message-passing primitives.

async reply(message)

Reply to the current sender.

async reply_error(code, detail="")

Reply with a structured error.

async send(target, message, *, options=None)

Send a message to another actor.

async spawn(actor_class, *, args=None, messages)

Spawn a child actor.

async schedule(delay, message)

Schedule a self-delivery after delay seconds.

sender

The ActorAddress of the current message sender (read-only).

self_address

This actor’s own ActorAddress (read-only).

Delivery

class DeliveryOptions

Configure delivery semantics for a send or ask.

mode: DeliveryMode

One of BEST_EFFORT, OBSERVABLE, AT_LEAST_ONCE, or DURABLE_AT_LEAST_ONCE.

deadline_ms

Delivery deadline in milliseconds. Messages not delivered before the deadline are dropped and recorded.

no_drop

If True, the mailbox will reject the enqueue instead of dropping when full.

class DeliveryReceipt

Returned from send() with observable delivery mode.

status: DeliveryStatus
message_id
class DeliveryStatus

Enum: ACCEPTED, REJECTED, DROPPED, DEAD_LETTER, EXPIRED, CIRCUIT_OPEN, QUARANTINED.

Addresses

class ActorAddress

Opaque identifier for an actor. Constructed internally; user code receives addresses from spawn(), resolve(), or ctx.self_address.

actor_id: int
incarnation: int
class ActorRef

Unified reference: a local ActorAddress or a remote proxy. Used as the target for send() and ask().

Errors

All binding errors inherit from HPActorError:

  • ActorError — an actor replied with an explicit error

  • ActorNotReadyError — operation on an actor not yet started

  • AskTimeoutError — ask() timed out

  • AskCancelledError — ask() was cancelled

  • RegistrationError — protobuf registry conflict

  • SerializationError — protobuf encode/decode failure

  • ResourceExhaustedError — queue or lease pool exhausted

  • SystemClosedError — operation after system shutdown

  • TopologyError — declarative topology failure
